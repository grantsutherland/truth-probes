STEP 2 — H2: INDUCED-LIE TEST  [OPTIONAL]
================================================================================
Status: OPTIONAL. This was the planned "contribution" back when H1 was expected to
be a clean replication. H1 instead produced the mechanistic finding above, which
is stronger and carries none of the belief-vs-intent contestability. Dropping H2
is a defensible scoping decision. Pursue only if time allows and only with
unhurried dataset design.

THE HARD PART: data/induced_lies.csv (does NOT exist yet -- must be hand-built).
  - Goal: prompts that lead the model to ASSERT a statement (true OR false),
    regardless of its truth, so we can separate the statement's ACTUAL truth value
    from the model's ASSERTED position.
  - Suggested columns: statement, actual_truth (0/1), asserted_position (0/1),
    prompt (the full context that induces the assertion), source_dataset.
  - Keep it clearly separate from the base M&T data.
  - THE CONTESTABLE BIT (design carefully, this is why H2 is risky): a prompt that
    "induces a falsehood" confounds (i) the model KNOWING X is false while
    asserting it (deception-like) vs (ii) the prompt SHIFTING what the model
    represents as true (belief change). This setup cannot fully distinguish them
    -- the write-up MUST say so (see README's belief-vs-intent caveat). Do not
    over-claim a "deception detector."

THE SCRIPT: scripts/04_induced_lie_test.py (not written yet)
  - Use the probes SAVED by 02 (data.load_probe), NO retraining.
  - For each induced-lie item: extract the activation at the SAME layer/token
    position while the model is asserting the statement (reuse
    activations.extract_activations on the assertion prompt; take the
    end-of-statement token of the asserted statement).
  - Apply BOTH LR and MM probes (use decision_function / forward margins, NOT hard
    labels -- save the signed margins so magnitude collapse is visible).
  - Record, per item and per probe, whether the probe output tracks ACTUAL truth
    or ASSERTED position. Report the LR-vs-MM split explicitly.
  - Three outcomes are all publishable: tracks actual truth (consistent with the
    model "knowing"), tracks asserted position (prompt shifted representation), or
    margin collapses toward zero (representation destabilized). Report which.
  - Interpret with the belief-vs-intent caveat stated plainly.

CONNECTION TO THE MECHANISM: MM direction is more causally implicated; if MM
tracks actual truth while LR tracks asserted position under induced falsehood,
that echoes the H1 finding that MM and LR directions diverge (cos ~0.77) and that
MM is the causally-relevant one. Worth framing H2 results against H1's MM-vs-LR
story rather than as a standalone deception probe.
